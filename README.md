# 🌤️ Weather & News CLI Dashboard

An interactive command-line interface (CLI) application in Python that fetches live meteorological data and top headlines for any city worldwide using external REST APIs.

✨ Features

Real-Time Weather: Live temperature (°C), conditions, humidity, and wind speed via WeatherAPI.

Top Headlines: Latest news articles via NewsAPI.

Secure Configuration: Environment isolation using python-dotenv to safeguard private keys.

Robust Error Handling: Resilient against invalid city queries, network timeouts, and missing API keys.
